
  NAME

      nebius compute instance get-by-name
        Retrieves detailed information about a specific VM instance by its parent and name.

  SYNOPSIS

      nebius compute instance get-by-name
        --name [required]
        --parent-id [required]

  OPTIONS

      --name (string) [required]

      --parent-id (string) [required]
