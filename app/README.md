# app/
The Spatial app: the organism core (our own, in Cordis's paradigm), the tri-pane, every face as a plugin in its own sandboxed frame, and the design data. Plain TypeScript using erasable syntax only, turned into ES modules by Node's built-in type stripping. No npm dependencies. Served only as a static, approved release by the frontdoor.
