Priorities: **A** = needed for a friend's node or a live Nostr demo; **B** = a security foundation; **C** = vision or later.

### A

**1. Invite-verified node creation ("Go Sovereign").** Suggested title: *invites: one-time 48 h invite (3 per member) unlocks node creation; hand-over ceremony*. CARRY-LIST [1] makes a valid invite the spend guard on node creation and prime has the signed kind 39701/39702 machinery (`packages/invites/index.mjs`, `ops/buzz-relay/admit.mjs`); sovereign's #22 spawns VMs but nothing gates creation on an invite or hands the node to a friend. Priority A — a friend's node is the stated next milestone.

**2. Node-to-node messaging.** Suggested title: *nostr 3: two sovereign nodes exchange gift-wrapped messages (transport, never authority)*. Peter: "nodes should talk to each other over Nostr" (#51). `crates/nostr` already carries NIP-44/59 and prime ran NIP-17 against a relay; the demo Peter wants to show Nostr people needs two nodes talking, not only a witnessed head. Priority A.

### B

**3. Delegation lineage and revocation store.** Suggested title: *aumlok: delegation lineage root→device→session→agent with attenuation, and a revocation store rechecked at every use*. CARRY-LIST [2]; the closed claim schema is specced in deep `aukora-kernel/SPEC.md` §5 and icloud BHUTAN §3.1; prime's `delegation.mjs` parses but never enforced. #24's add-machine is the first link only. Priority B.

**4. Pin-drift check.** Suggested title: *launcher: a change to the patch set or launcher fails until its pins are re-reviewed*. CARRY-LIST [1] (Prime #7 lineage); no sovereign issue names it. Priority B.

**5. Reproducible build.** Suggested title: *release: rebuild from pristine and byte-compare*. CARRY-LIST [2]; Prime measured 41 differing outputs (#1 there). Without it the release floor approves bytes nobody can re-derive. Priority B.

**6. Attack corpora port.** Suggested title: *immune: locate and port the 815-attack corpus, the 81 aumlok-id issues and the 5,360 Pentora vectors*. CARRY-LIST [1] lists them as the executable spec and marks the corpus "UNVERIFIED: locate it"; the antibody ratchet (#41) is exactly where they belong once found. Priority B.

**7. **8. Member exit.** Suggested title: *owner: leave with keys, memory and receipts — full export a stranger can verify*. CARRY-LIST [2]; icloud BHUTAN §2.1. #22 says "backup/export" but the exit finish line (everything, verified offline, on a stranger's machine) is not written anywhere. Priority B.
